# Repository discovery

## Scope and freshness

Repository root, branch/commit, date, dirty files and whether this is initial discovery or a refresh.

## Repository inventory

| Product area / paths | Purpose | Inspection performed | Coverage / limitations |
|---|---|---|---|

Enumerate the repository before selecting files to read. Include hidden project configuration; record excluded dependencies, generated output, binaries, secrets and unreadable files without copying sensitive contents.

## Documents learned from

|---|---|---|---|

## Understanding saved in Planner

Link concept.md, baseline.md, prd.md, ux.md, architecture.md (or plan.md), decisions.md and roadmap.md as they are written. Distinguish current implementation from intended or proposed behavior. Keep epics and remaining tasks in tasks.json through the plan import workflow.

## Open questions and uninspected areas

Record unknowns and conflicts requiring user input or further verification. Do not treat an uninspected capability as absent.
