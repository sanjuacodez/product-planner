# Resume

Read the manual, state.json, tasks.json, decisions.md, risks.md and recent log entries; run status --json and task validate. Inspect the repository for partial outputs. For existing products compare baseline.md and relevant lessons.md with the current branch/commit and dirty files; revalidate evidence for changed sources using `guides/existing-products.md` before relying on old summaries. Briefly identify the last completed milestone and next action. In init/planning continue pp-plan from the first incomplete step, reusing answers and documents. In build continue pp-build, recovering active/review tasks before picking new work. If every remaining task is blocked, recheck causes and continue any newly available work; otherwise give consolidated blockers. In done report completion; if the user requested additional scope use pp-plan for that change. Never infer approval solely from a phase label when handoff is incomplete.
