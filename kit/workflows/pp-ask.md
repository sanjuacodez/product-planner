# Ask

Read the manual and current state. Use `memory search` if an index exists, then read the relevant source docs/code. Answer the user's question with concrete evidence and file paths. Distinguish implemented behavior from planned scope. For requested dashboard information create/update dashboard/<slug>.json (set `tab` to overview, tasks, roadmap, research, docs or activity to choose where it appears) and regenerate; open if asked. Record a consequential user decision in decisions.md and synchronize relevant tasks/docs. For a substantial scope change return to planning for the changed scope while preserving completed work and the previous approved baseline. A question alone does not cancel an ongoing build.
