I want a WooCommerce extension that sets a minimum order amount per customer role. We will sell it on the WooCommerce Marketplace, so it must meet the marketplace's quality, security and coding expectations for a WordPress/WooCommerce extension. Make sensible choices for any details I haven't specified and build it without asking me to choose a stack. Use plain PHP with no build step and no runtime Composer dependencies. Put the plugin in the folder min-order-by-role with the main plugin file min-order-by-role/min-order-by-role.php. It needs WooCommerce and targets the classic (shortcode) cart and checkout pages.

Settings: add a settings area under WooCommerce > Settings (its own tab or a section) with one minimum amount field for every user role registered on the site, plus one for Guest (visitors who are not logged in). Store all amounts in a single option named min_order_by_role_minimums: an associative array keyed by role slug, using the key guest for visitors, with the amounts as decimal numbers (strings or numbers). The form fields post as min_order_by_role_minimums[<role slug>], for example min_order_by_role_minimums[customer] and min_order_by_role_minimums[guest]. An empty, zero, negative or non-numeric amount means no minimum for that role.

Rules: compare the cart subtotal (WC()->cart->get_subtotal(), before discounts, shipping and tax) with the minimum for the current customer. A logged-in customer's minimum is the highest minimum configured among all of their roles; roles without a minimum are ignored, and if none of their roles has one there is no minimum. Visitors who are not logged in use the guest amount. The order is below the minimum only when the subtotal is strictly less than it, so a subtotal exactly equal to the minimum is allowed. An empty cart never shows the notice.

Messages: when the cart is below the minimum, show a notice on the cart page with exactly this text: "A minimum order of {minimum} is required. Your current subtotal is {subtotal}." where both amounts are formatted with WooCommerce's wc_price() (for example "A minimum order of $50.00 is required. Your current subtotal is $49.99."). Checkout validation must reject placing the order while below the minimum, with the same text as a WooCommerce error. At or above the minimum, show no notice and do not block checkout.

Build it, test it and document it, including installation and settings. Use your recommendations for unspecified details. You are authorized to implement and verify the requested scope.
