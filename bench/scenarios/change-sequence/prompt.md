I want a small shopping-cart pricing core for an online shop. Make sensible choices for any details I haven't specified and build it without asking me to choose a stack. Use plain JavaScript with no runtime dependencies and no UI or server. Put an ES module in cart.js exporting createCart(). Each call returns an independent in-memory cart. All prices are integer cents.

Support these operations. addItem(sku, unitPrice, quantity) adds a line, or increases the quantity of an existing line, and returns the line's resulting quantity. If the SKU is already in the cart with a different unit price, addItem throws an Error with code PRICE_MISMATCH. removeItem(sku, quantity) reduces a line's quantity and returns the remaining quantity; a line that reaches 0 is removed from the cart. Removing a SKU that is not in the cart, or more than its quantity, throws an Error with code INVALID_REMOVE. items() returns an array of { sku, unitPrice, quantity, lineTotal } in the order the lines were added, where lineTotal is unitPrice × quantity; changing the returned array or its objects must not change the cart. subtotal() returns the sum of line totals (0 for an empty cart). applyCoupon(code) sets the cart's coupon: SAVE10 takes 10% off the subtotal, rounded down to a whole cent; FLAT500 takes 500 cents off but never more than the subtotal. Only one coupon is active at a time, so applying a coupon replaces the previous one. An unknown code throws an Error with code UNKNOWN_COUPON and keeps the previous coupon. discount() returns the active coupon's discount computed from the current subtotal (0 without a coupon), and total() returns subtotal() − discount().

A SKU must be a nonempty string, unitPrice a nonnegative integer and quantity a positive integer; otherwise throw an Error with code INVALID_INPUT. Failed operations must not change the cart.
